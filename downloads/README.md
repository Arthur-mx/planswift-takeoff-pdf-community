# Install Takeoff PDF Community 1.1.0

Download **both** files:

1. [Python helpers — ZIP](https://github.com/Arthur-mx/planswift-takeoff-pdf-community/raw/refs/heads/main/downloads/Takeoff-PDF-Community-1.1.0.zip)
2. [PlanSwift plugin — SwiftPluginPackage](https://github.com/Arthur-mx/planswift-takeoff-pdf-community/raw/refs/heads/main/downloads/Takeoff%20PDF%20Community%201.1.0.SwiftPluginPackage)

Extract the helper ZIP and run **Install.cmd**. Then **double-click the SwiftPluginPackage** on Windows with PlanSwift installed and follow its installation prompts. If the file association is missing, import the package from PlanSwift's Plugins tab instead.

The package installs the PlanSwift command; it does not install Python or the helper files. The command is currently named **Export takeoff to pdf** under **Claude Scripts → Misc**. Its Plugin Type is **Script Code** and **Shell Execute stays blank**.

Requirements and troubleshooting: [INSTALL.txt](../INSTALL.txt).

For review or customization, download the [complete unencrypted PlanSwift script](../Takeoff%20PDF%20Community%20-%20PlanSwift%20Script.txt) as well. It is intentionally supplied separately from the helper ZIP. The helper source and matching bridge source are licensed as described in [LICENSE.txt](../LICENSE.txt) and [THIRD_PARTY_NOTICES.txt](../THIRD_PARTY_NOTICES.txt).

The package was exported by the maintainer and uploaded unchanged. Its executable Pascal statements match the published 1.1.0 script. PlanSwift's duplicate Scripts.XML copy changes punctuation in comments only.

SHA-256 checksums for the two downloads are in [SHA256SUMS.txt](SHA256SUMS.txt).
