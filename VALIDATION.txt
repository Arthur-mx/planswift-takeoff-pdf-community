VALIDATION - COMMUNITY 1.1.0
Date: 2026-10-11

Passed 182 automated tests on Windows with Python 3.13 and PyMuPDF 1.26.3.
Command: python -m unittest discover -v

NEW SHARED FEATURES
- Visual legend defaults: validation, proportional areas, physical font size,
  portrait/landscape settings, manual PlanSwift Legend priority and collision
  fallback. Direct exports and preview workers read COMMUNITY preferences.
- Real Tk tests exercise the main-window shortcut, editor controls, saved
  preferences and preview rebuilds preserving grouped order/removal/history.
- Independent takeoff/page-item modes, saved through Cancel and Preview/Back;
  RESULT_V5 handoff includes the new page-item field.
- Wider settings scrollbar, stable focus on visible controls and automatic
  scrolling to controls reached by keyboard below the visible area.
- Annotation parsing, visibility, rotated page transforms, cloud winding and
  outline-only output, one stamp per two control points, searchable labels,
  dedicated layers, tab direction, timestamps and reported font substitutions.
- An integrated SectionRecordsV1 export combines the community quantity
  allocation with annotations and saved defaults, in both raster and source-PDF
  modes and each of the three page-item visibility settings.

RETAINED COMMUNITY BEHAVIOR
The suite also covers section grouping, page-share calculations and Qty units,
source-file/page-label matching, native layer actions and highlights, multiplier
placement, page flags, preview ordering/removal/Undo, thumbnail/list preferences,
and the separate installation/settings paths. The installer-copy test checks
all nine runtime modules and preserves existing user preferences.

Source checks confirm that personal linked-item/color/filter conventions and
workstation paths remain excluded, and that the rewritten community collector
and SectionRecordsV1 normalization remain in use. Personal tracked working
files have no changes relative to their staged upload baseline.

VISUAL CHECK
A separate, entirely synthetic sheet was rendered through the community builder
and inspected using a Poppler PNG render. It contains a clear cloud outline,
one angled APPROVED stamp, an angled REVIEW tab, two takeoff sections allocated
to a searchable 500 LN FT row, a 12-point saved-position legend and the multiplier.
No customer drawing or sample manifest is included in the release package.
The previously approved public demo PDF and screenshot are unchanged.

INSTALLATION / HOST LIMITS
This update verifies the installer file set and saved preferences in automated
tests; it is not a new clean-machine installation certification. No live
PlanSwift job was modified. Python-side tests and static bridge checks do not
compile or execute PlanSwift's embedded script engine.

Before sharing a SwiftPluginPackage, install the 1.1.0 helpers and replace the
entire bridge TXT in the separate community plugin, then test a small job copy:
- Nested page folders and a custom selected-page order.
- Area, Linear, Count and Wall Area with parent Qty/inputUnits allocation.
- All takeoff/page-item mode combinations, including hidden annotations.
- Cloud outlines, two-point stamps, angled tabs, notes/highlighters/dimensions.
- Saved portrait/landscape defaults, existing Legend priority and fallback.
- Preview rebuild, reorder/remove/Undo, Back, and Print flags on Cancel.
- Source/raster backgrounds and legend interaction in the saved PDF reader.
Record exact PlanSwift/PDF-reader versions and verify package import in another
Windows account or machine. See SOURCE_REVIEW.txt for provenance-review scope.
