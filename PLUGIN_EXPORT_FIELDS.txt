Description (paste this):
Independent, open-source PDF exporter for PlanSwift. Export takeoff with searchable
legend text, clickable layer visibility controls and selection-style highlighting.
Includes automatic or user-positioned legends, raster/source PDF backgrounds,
source sheet checks, a searchable page tree, saved Print flags, custom PDF order,
and a finished-PDF preview with thumbnails/list view, multi-page dragging, removal
and Undo. Requires the matching Takeoff PDF Community Python helper ZIP and a
licensed PlanSwift installation. Install the helper ZIP with Install.cmd first.
AGPLv3; editable source supplied separately. Unofficial community project, not
affiliated with or endorsed by ConstructConnect. First community release: please
verify the export against your job before relying on it.

EXPORT CONTENTS
Create/export ONLY the new community plugin command with the complete community
script. Do not export your existing personal plugin, custom assemblies, job data,
private event handlers, saved folder settings or imported stock artwork. The new
script does not need embedded image or FolderLocation properties on the plugin.
Keep all events unencrypted. Review the export contents before the final step.
