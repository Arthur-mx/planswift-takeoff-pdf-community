INSTALL TAKEOFF PDF COMMUNITY 1.1.0

REQUIREMENTS
- Windows with a licensed PlanSwift installation and access to its plugin tools.
- 64-bit Python 3.10-3.13, including pip and Tcl/Tk. Python 3.13 was used for
  validation. Download Python from https://www.python.org/downloads/windows/ .
  Include the launcher and Tcl/Tk options during installation.
- Internet access during installation to obtain PyMuPDF 1.26.3 from PyPI.
- A desktop PDF reader with optional-content/layer-action support for the
  interactive legend. Revu and PDF-XChange worked in the existing user's tests.

NORMAL INSTALLATION
1. Download the ZIP and the matching SwiftPluginPackage. Keep the separate
   PlanSwift Script TXT if you want to review or customize the source.
2. Extract ALL files from the ZIP. Do not run from inside the ZIP preview.
3. Close an already-open export or preview window. Double-click Install.cmd.
   It prefers Python 3.13, then checks another supported Python installation.
   It creates a dedicated environment, installs the pinned PDF engine and checks
   that the PDF and Tk modules load. Wait for "Installation complete."
   Administrator access is normally unnecessary.
4. Double-click the matching .SwiftPluginPackage file in Windows. With PlanSwift
   installed, its registered file association opens the package installer.
   Follow the prompts. If Windows does not recognize the file, use PlanSwift's
   Plugins tab > Import Plugin Package command instead (labels vary by version).
5. Open a small COPY of a job, run Takeoff PDF Community and choose Preview PDF.
   Check page totals, units, alignment, legend placement and page order. Save a
   test PDF and try its eye controls and description highlights in your reader.

DOWNLOADS
The repository's downloads/ folder contains BOTH required files:
- Takeoff-PDF-Community-1.1.0.zip
- Takeoff PDF Community 1.1.0.SwiftPluginPackage
https://github.com/Arthur-mx/planswift-takeoff-pdf-community/tree/main/downloads
The plugin package installs the PlanSwift command. Install.cmd installs its
Python helpers separately; the package alone does not install Python or helpers.
The exported command is named "Export takeoff to pdf" in Claude Scripts > Misc.
Keep Plugin Type set to Script Code and leave Shell Execute blank. The script
finds the community helper installation automatically for each Windows user.

INSTALL LOCATION
%LOCALAPPDATA%\PlanSwift\Takeoff PDF Community
The script finds this folder automatically for each Windows account. Install
under the same Windows user that runs PlanSwift. Do not edit paths in the script.
The runtime is in runtime\Scripts\python.exe. Preferences are in preferences.json;
remembered export folders are in export_folders.txt. No elevation is required
just to place these files, although company policies may require IT assistance.

BUILDING YOUR OWN PLUGIN (IF NO SwiftPluginPackage IS PROVIDED)
Create a new, separate plugin item using PlanSwift's plugin authoring tools.
Paste the ENTIRE separate PlanSwift Script TXT into its Pascal Script Code event,
replacing the editor contents. Copy from the plain TXT, never from a diff view
with removed lines. Use the normal click/execute event for the plugin command.
The script requires no custom Source/Building fields, embedded image properties,
FolderLocation property on the plugin, or additional icon-extractor utility.
You can use assets/print_flag.png as the command icon. Export settings and package
metadata are in PLUGIN_EXPORT_FIELDS.txt. Exact authoring steps depend on the
PlanSwift version and must be verified by the package maintainer.

UPDATING
Close export/preview windows. Extract a new release, rerun Install.cmd and run
its matching SwiftPluginPackage when the script changes. Only shipped Python and
asset files are overwritten; preferences and remembered folders are retained.
Keep the ZIP and script versions together. Reinstalling updates the dedicated
PDF dependency to the version pinned by that release.

UNINSTALLING
Remove the community plugin through PlanSwift. After closing its windows, remove
ONLY the folder listed above if you also want to remove its runtime/preferences.
Exported PDFs and PlanSwift jobs are outside that folder and are not removed.
Saved Print flags on project pages remain until you clear them in the form.

TROUBLESHOOTING
"Install first": check the Windows account and installation path above.
"No module named fitz": rerun Install.cmd; do not install the unrelated package
named "fitz". The dependency is named PyMuPDF.
Missing tkinter: repair/install Python with Tcl/Tk support.
Python not found: install supported 64-bit Python, then rerun Install.cmd.
Company network blocks pip: ask IT to provide the pinned PyMuPDF wheel. This ZIP
contains source, not an offline copy of Python or third-party binary wheels.
Blank/missing raster page: verify PlanSwift can open it and that its TIFF and
Data.xml are accessible. Network job storage must be available to your account.
Wrong source matching/alignment: see USER_GUIDE.txt; do not use a different
revision, crop or orientation. Source PDF mode still needs PlanSwift's TIFF.
Preview/Save cannot overwrite a PDF: close that PDF in its reader, or use a new name.
A PlanSwift syntax error: copy the full plain script again and report the line
number plus your exact PlanSwift version. Host compilation remains version-specific.

UPGRADING TO 1.1.0
Run Install.cmd from this ZIP, then replace the ENTIRE PlanSwift Script Code
with the matching complete community TXT (or import its matching plugin
package). Both halves changed: the picker now sends separate page-item
choices using RESULT_V5. Older scripts cannot read that response.
The installer also adds pdf_legend_defaults.py and pdf_page_annotations.py.
Saved community preferences are retained; personal preferences are untouched.
Page items initially use Visible items. For a background-only PDF, choose
None under BOTH Takeoff items and Page items. Saved legend defaults initially
remain disabled, preserving automatic placement until you configure them.
